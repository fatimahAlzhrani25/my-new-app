لوحة الإدارة

أدخلي رمز الوصول الشخصي (Personal Access Token) من حسابك في GitHub لمرة واحدة — سيُحفظ في متصفحك فقط ولن يُرسل لأي جهة غير GitHub.


لإنشاء الرمز: GitHub → Settings → Developer settings → Personal access tokens → Generate new token (classic) → فعّلي صلاحية repo فقط.

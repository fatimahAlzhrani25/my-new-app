# ملف الأداء الوظيفي

موقع بسيط (HTML/CSS/JS بدون إطار عمل) لعرض ملف شواهد الأداء الوظيفي، بنسختين:

- `index.html` — النسخة الكاملة الخاصة بالمعلمة.
- `supervision.html` — نسخة الاطلاع المخصصة للإشراف التربوي (بدون تعديل، مع روادع: تعطيل النسخ والزر اليمين والطباعة، وعلامة مائية باسم المُطّلِع والتاريخ).

> تنبيه: روادع نسخة الاطلاع لا تمنع التقاط الشاشة تقنيًا (لا توجد طريقة برمجية تضمن ذلك على الويب) — هي رادع وتوثيق لهوية المُطّلِع فقط.

## إضافة المحتوى والشواهد

كل المحتوى (البيانات الأساسية، عناوين المعايير، الشواهد) موجود في ملف واحد:

```
assets/js/data.js
```

عدّلي القيم في `BASIC_INFO` وأضيفي عناصر داخل `evidence` لكل معيار — التغييرات تظهر تلقائيًا في الصفحتين لأنهما تقرآن من نفس الملف.

## المعاينة محليًا

```
python3 -m http.server 8000
```

ثم افتحي `http://localhost:8000` في المتصفح.

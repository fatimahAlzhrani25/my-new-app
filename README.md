# ملف الأداء الوظيفي

موقع بسيط (HTML/CSS/JS بدون إطار عمل) لعرض ملف شواهد الأداء الوظيفي، بثلاث صفحات:

- `index.html` — النسخة الكاملة الخاصة بالمعلمة.
- `supervision.html` — نسخة الاطلاع المخصصة للإشراف التربوي (بدون تعديل، مع روادع: تعطيل النسخ والزر اليمين والطباعة، وعلامة مائية باسم المُطّلِع والتاريخ).
- `admin.html` — لوحة إدارة لإضافة/تعديل البيانات والشواهد مباشرة من المتصفح، دون الحاجة لتعديل كود.

> تنبيه: روادع نسخة الاطلاع لا تمنع التقاط الشاشة تقنيًا (لا توجد طريقة برمجية تضمن ذلك على الويب) — هي رادع وتوثيق لهوية المُطّلِع فقط.

## إضافة المحتوى والشواهد

الطريقة الموصى بها: افتحي `admin.html` وسجّلي دخول برمز وصول شخصي (Personal Access Token) من GitHub (مرة واحدة فقط، يُحفظ في متصفحك). من هناك عدّلي البيانات الأساسية وأضيفي الشواهد لكل معيار، واضغطي "حفظ التغييرات" — التعديل يُحفظ مباشرة في `assets/data.json` ويظهر تلقائيًا في الصفحتين الأخريين.

لإنشاء الرمز: GitHub → الإعدادات (Settings) → Developer settings → Personal access tokens → Generate new token (classic) → فعّلي صلاحية `repo` فقط.

جميع البيانات (الاسم، عناوين المعايير، الشواهد) مخزّنة في ملف واحد يمكن أيضًا تعديله يدويًا إذا رغبتِ:

```
assets/data.json
```

## المعاينة محليًا

```
python3 -m http.server 8000
```

ثم افتحي `http://localhost:8000` في المتصفح.

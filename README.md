# تفويج الروضة (Kindergarten Dismissal App)

تطبيق جوال (Expo / React Native) لمساعدة معلمات ومسؤولات الروضة على تفويج الأطفال أثناء الانصراف، ومتابعة خط سير كل طفل من الفصل حتى وصوله إلى ولي أمره.

هذه نسخة أولية (Prototype) تعمل ببيانات وهمية (بدون خادم خلفي)، وتستهدف واجهة المعلمة/الإدارة فقط.

## الميزات

- **الرئيسية**: نظرة عامة على تقدم الانصراف اليومي وعدد الطلاب في كل مرحلة.
- **التفويج**: تنظيم الطلاب في دفعات (حسب البوابة/وسيلة الاستلام)، مع إمكانية نداء الدفعة دفعة واحدة.
- **الطلاب**: قائمة بحث وتصفية لجميع الطلاب مع حالتهم الحالية.
- **بيانات الطالب**: خط سير مفصّل (Timeline) لمراحل الانصراف مع الوقت، وبيانات ولي الأمر مع إمكانية الاتصال المباشر.

## مراحل خط السير

في الفصل ← تم النداء ← في الممر ← في ساحة الانصراف ← مع ولي الأمر ← تم التسليم

## التشغيل

```bash
npm install
npm run start   # أو: npm run ios / npm run android / npm run web
```

يستخدم المشروع [Expo Router](https://docs.expo.dev/versions/v57.0.0/) (SDK 57) للتنقل بين الشاشات.

## البنية

```
app/                  شاشات التطبيق (Expo Router)
src/types.ts          نماذج البيانات ومراحل الانصراف
src/data/mockData.ts  بيانات تجريبية (فصول، دفعات، طلاب)
src/store/            إدارة الحالة (Context + Reducer)
src/components/       مكونات مشتركة (Timeline، StatusBadge، ...)
```
